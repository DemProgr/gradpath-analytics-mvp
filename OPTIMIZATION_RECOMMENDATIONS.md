# Оптимизация и улучшение страницы "Абитуриенты"

## 🎯 Основные проблемы, которые нужно исправить

### 1. ⚠️ Критические проблемы

**A. Моковые данные в UniversitiesSection**
- Использует статические данные из `src/data/universityMarks.ts`
- Не показывает актуальную информацию о проходных баллах
- Нет динамической загрузки из базы данных

**B. Не работают ссылки в футере**
- `FooterSection` принимает `onNavigate`, но в `Applicants.tsx` передается пустая функция
- Ссылки ведут на 404 страницы
- Нет плавной прокрутки к секциям

**C. Отсутствует хэш-навигация**
- Страница не реагирует на URL с хэшами (например, `/applicants#professions`)
- Нельзя делиться ссылками на конкретные секции

### 2. 🚀 Оптимизации производительности

**A. Ленивая загрузка секций**
- Загружать секции только когда они видимы
- Оптимизировать `ProfessionsSection` - сейчас загружает все профессии сразу
- Добавить виртуальный скролл для больших списков

**B. Кеширование данных**
- Кешировать результаты запросов к Supabase
- Избегать повторных запросов при переключении между секциями
- Использовать `react-query` или `swr` для управления состоянием

**C. Оптимизация рендеринга**
- Использовать `React.memo` для компонентов, которые не меняются
- Оптимизировать `UniversitiesSection` - сейчас создает много сложных маппингов
- Уменьшить количество ре-рендеров в `ProfessionsSection`

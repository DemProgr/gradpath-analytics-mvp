Модуль 1. Университетский профиль
Что это
После регистрации пользователь становится частью определённого университета.
Пример:
БГУИР
Факультет компьютерных систем
Программная инженерия
3 курс
________________________________________
Для чего нужен
Вся аналитика платформы строится именно вокруг образовательной траектории.
Например:
БГУИР
↓
Программная инженерия
↓
Выпуск 2028
↓
Карьерный путь
________________________________________
Минимальная реализация
Регистрация:
•	email; 
•	вуз; 
•	факультет; 
•	специальность; 
•	курс. 
Подтверждение:
•	университетская почта; 
•	студенческий билет.

Модуль 4. Каталог стажировок
Это заменяет модуль вакансий.
Именно здесь я вижу первую реальную ценность платформы.
________________________________________
Где брать стажировки
Не создавать вручную.
Собирать из нескольких источников.
Источник №1
Карьерные центры вузов.
Практически каждый вуз публикует:
•	практики; 
•	распределение; 
•	стажировки. 
________________________________________
Источник №2
Карьерные страницы компаний.
Например:
•	EPAM; 
•	IBA Group; 
•	Andersen; 
•	Банки; 
•	МТС; 
•	А1. 
________________________________________
Источник №3
Формы подачи.
Компания самостоятельно публикует стажировку.
________________________________________
Что видит студент
Пример карточки:
EPAM Internship

Направление:
Java Development

Длительность:
3 месяца

Формат:
Онлайн

Оплачиваемая:
Да

Требования:
Java Core
English B1
